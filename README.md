# 메이플 레이드 정산기

메이플 레이드 드랍템 정산을 위한 정적 웹사이트입니다.

## 포함 파일

- `index.html`: 메인 계산기
- `privacy.html`: 개인정보처리방침
- `ads.txt`: AdSense 검증 파일
- `DEPLOY_GUIDE.md`: 배포 및 설정 가이드

## 배포

이 프로젝트는 정적 HTML 사이트이므로 GitHub + Vercel 조합으로 바로 배포할 수 있습니다.

## 추가 설정이 필요한 항목

- 실제 사이트 주소로 `example.com` 교체
- Firebase 설정값 입력 시 공유 기능 활성화
- Google AdSense 퍼블리셔 ID 및 광고 슬롯 ID 입력

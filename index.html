Web Calculator

메이플 레이드 정산기

드랍템 판매가, 실수령액, 획득자를 입력하면 실수령액과 송금 경로를 계산합니다. Firebase를 연결하면 공유 링크로 같은 데이터를 불러올 수 있고, 도메인을 연결하면 실제 사이트로 공개할 수 있습니다.

계산기 시작 배포 가이드 보기
배포 준비 상태
  • 정적 사이트 진입 파일: `index.html`
  • 광고 파일: `ads.txt`
  • 공유 저장소: Firebase 설정 후 활성화
  • 도메인 연결 후 Google AdSense 신청 가능

공유 링크

Firebase가 설정되어 있으면 생성한 링크로 다른 사람도 같은 정산 화면에 접속할 수 있습니다.

Firebase 설정 전: 현재 브라우저에만 임시 저장됩니다.

파티원

정산 대상 이름을 입력하세요.

`지원금`이 체크된 파티원은 입력한 지원금만큼 더 받고, 나머지 파티원이 그 금액을 균등하게 분담합니다.

드랍 아이템

경매장 판매가 또는 실수령액과 획득자를 입력하세요.

`가위`가 체크된 아이템은 실수령액에서 카르마의 가위 가격을 자동으로 차감합니다.

배포 체크

  1. 1. `index.html`을 GitHub Pages, Netlify, Vercel 중 하나에 올립니다.
  2. 2. 커스텀 도메인을 연결하면 `SITE_CONFIG.siteUrl`과 canonical/OG URL도 그 주소로 다시 바꿉니다.
  3. 3. Firebase 프로젝트를 만들고 Firestore를 켭니다.
  4. 4. `ads.txt`와 AdSense 코드의 퍼블리셔 ID를 실제 값으로 교체합니다.
  5. 5. Search Console, AdSense에서 도메인 소유권 검증 후 광고 승인을 진행합니다.

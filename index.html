메이플 레이드 정산기

드랍템 판매가, 실수령액, 지원금, 가위값을 반영해서 파티원별 최종 정산 금액과 송금 경로를 한 번에 계산합니다.

사용안내

왜 이 계산기를 쓰나요?

기존 방식은 아이템을 판 사람이 각자 따로 분배를 보내야 해서 택배를 여러 번 보내고 수수료도 여러 번 냅니다. 예를 들어 A가 3,000만, B가 8,000만 실수령액을 먼저 챙겼다면 A와 B가 각각 나머지 파티원에게 다시 송금해야 합니다. 이 계산기는 판매 담당자가 이미 받은 금액을 먼저 반영한 뒤 부족하거나 초과한 금액만 송금 경로로 정리해서, 불필요한 택배와 수수료를 최대한 줄여 줍니다.

1. 파티원과 지원금

파티원 이름을 입력하고, 지원금이 필요한 사람이 있으면 `지원금`을 체크하세요.

2. 빠른 아이템 입력

아이템명 입력 후 `Enter`를 누르면 경매장 판매가로 이동합니다. 판매가 입력 후 다시 `Enter`를 누르면 다음 줄이 자동 생성되고 바로 다음 아이템명 칸으로 넘어갑니다.

3. 판매가와 옵션

경매장 판매가를 입력하면 실수령액이 자동 계산되고, 실수령액만 직접 입력해도 됩니다. `가위`, `내판`, `판매완료` 옵션도 같은 줄에서 바로 반영됩니다.

4. 저장과 공유

`코드 생성`으로 방 코드를 만들고 `저장`을 누른 뒤 `링크 복사`를 누르면, 다른 사람도 같은 정산 내용을 그대로 열어볼 수 있습니다.

공유 링크

저장 후 링크를 복사하면 같은 정산 내용을 다시 열어볼 수 있습니다.

Firebase 설정 전: 현재 브라우저에만 임시 저장됩니다.
1. `코드 생성`을 눌러 현재 정산용 코드를 만듭니다.
2. 내용 입력 후 `저장`을 눌러 Firebase에 올립니다.
3. `링크 복사`로 공유하면 같은 내용이 그대로 열립니다.
여러 사람이 동시에 같은 링크를 수정하면 저장 충돌이 날 수 있습니다. 저장 전에 `최신 불러오기`로 가장 최근 저장본을 확인하세요. 충돌이 감지되면 저장이 막히고 다시 불러오기를 안내합니다.

정산 정보

공유용 제목을 직접 적고, 날짜는 오늘 날짜를 기본값으로 두고 필요하면 수정하세요.

파티원

정산 대상 이름을 입력하세요.

`지원금`이 체크된 파티원은 입력한 지원금만큼 더 받고, 나머지 파티원이 그 금액을 균등하게 분담합니다.

드랍 아이템

경매장 판매가 또는 실수령액과 획득자를 입력하세요.

`가위`가 체크된 아이템은 실수령액에서 카르마의 가위 가격을 자동으로 차감합니다.
`내판`을 체크하면 경매장 판매가는 최저가 기준으로 사용되고, `실수령액`은 내판 구매가로 자동 계산됩니다. 판매가를 비워두면 실수령액 칸에 내판 구매가를 직접 입력할 수 있습니다.
